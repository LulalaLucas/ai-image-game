# 真实，还是 AI？

一款辨别真实照片与 AI 生成图片的小游戏。观察画面中的细节，看看你能答对几题。

[点击开始游戏](https://lulalalucas.github.io/ai-image-game/)

## 游戏规则

每轮共 6 题，包含 3 张真实照片和 3 张 AI 生成图片，出题顺序随机。玩家需逐题判断图片是真实照片还是 AI 生成，可点击图片放大查看细节。每答对一题得 1 分，答错不得分，满分为 6 分。完成本轮后可查看得分和答题回顾，点击“换一组图片”开始新一轮。

## 操作方式

- 点击“真实照片”或“AI 生成”作答，提交后即可查看结果，再进入下一题。
- 点击图片可放大查看，支持放大与缩小。
- 使用键盘时，按 R、左方向键或 1 选择真实照片，按 A、右方向键或 2 选择 AI 生成。
- 重新开始时会更换图片，并优先抽取本次游玩中尚未出现的题目。
